What was the problem you were solving in the projects for this course?  

The project’s main problem was deciding what data structure to use for the ABCU team. They needed to load course data from a file, view a list of all courses
in alphabetical order, and look up what prerequisites course needed.


How did you approach the problem? Consider why data structures are important to understand. 

I approached the problem by first creating a pseudocode diagram, going through each data structure like vector, hash tables, and binary search tree across three
milestones. It allowed me to compare how each performed and how they are structured. Understanding data structures is critical because the choice made can impact
on how efficient the program can store, search, and organize data. Selecting one data structure over another or one not best suited can lead to poor performance or
an unoptimized program.



How did you overcome any roadblocks you encountered while going through the activities or project?

The biggest roadblock for me was implementing the remove function and the recursive destructor in the binary search tree. I got stuck on pointer management a few 
times. What helped was going back to the earlier labs. Adding lots of small test prints also made it easier to see what the program was doing and what was going wrong.


How has your work on this project expanded your approach to designing software and developing programs?  

This project taught me the importance of planning before doing a lot of coding. By creating pseudocode and performing an analysis first, I was able to make an
informed decisions on how to best approach the project. I have a better understanding about how different data structures can handle data. 



How has your work on this project evolved the way you write programs that are maintainable, readable, and adaptable?

I’ve gotten better at writing comments that explain why something is done, not just what the line does. I also try to keep functions focused on one job and make
my code more modular. Making my code easier to read and modify, especially when coming back to code throughout the weeks.
